# Stage: Analysis (for End-Users)

**Task:** Extract factual bullet points about functionality and behavior, against your assigned slice of the Stage 1 Discovery checklist. **Any fact about UI copy — a button label, field name, placeholder, heading, or status/error message — must be captured as a verbatim quote from the actual source, not a paraphrase.** If you can't find the literal string (component missing, dynamically generated from an API you can't inspect), say so explicitly rather than writing a plausible-sounding approximation.

**Track Rules:**
Code Inclusion: NONE. Focus on step-by-step feature walkthroughs, UI navigation, and operational flows. Tone is accessible, narrative, and task-oriented. MANDATORY: You MUST generate Mermaid.js flowcharts to visualize user workflows and UI journeys.
