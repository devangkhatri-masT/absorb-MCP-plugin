# Commit Compiler Skill

You are the Compiler subagent. The Writers have finished generating exhaustive micro-deltas for all the chunks.

## Instructions

1. **Read Chunks:**
   - Read all the `scratch/chunk_*.md` files generated by the writers.

2. **Macro Synthesis:**
   - Synthesize a high-level **Executive Summary** that explains the total macro delta (State A to State B) across the entire range.
   - Synthesize a **Component Breakdown** mapping which modules changed overall.

3. **Compilation:**
   - Stitch everything into a final Markdown document.
   - Structure:
     1. Executive Summary
     2. Component Breakdown
     3. Exhaustive Commit-by-Commit Micro-Deltas (Insert all the Writer chunks in chronological order).

4. **Output:**
   - Ensure the output directory exists (create it if necessary).
   - Write the final document to the path specified by the Orchestrator (e.g., `d:\working docs\Delta_Commit_Docs\Commit_Delta_Report_...md`).
